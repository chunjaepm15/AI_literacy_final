# 우주탐정단 플랫폼 화면 설계 구성안

요청해주신 변경된 플랫폼 흐름도(`플랫폼 흐름2.png`)와 피드백 사항들을 반영한 전체 화면 설계 구성(UI 흐름도)입니다.

## 📌 전체 흐름 (User Flow)
**로그인 ➔ 특별학습 GNB ➔ 우주탐정단 ➔ 진단평가 ➔ 추천학습 ➔ 상세학습 ➔ 리스트 복귀**

---

## 🖥️ 단계별 화면 설계 상세

### 1. 시연용 로그인 화면 (Dummy Login Page)
* **목적**: 실제 밀크T 플랫폼 연동 전, 시연을 위해 거쳐가는 간단한 확인용 화면.
* **UI 구성**: 
  * 밀크T 로고 및 배경
  * 아이디/비밀번호 입력 폼 (모형)
  * [로그인] 버튼 (클릭 시 다음 화면으로 이동)

### 2. GNB (Global Navigation Bar) 및 메인 진입
* **목적**: 밀크T 내 특별학습 메뉴를 통해 진입하는 과정 모사.
* **UI 구성**:
  * 상단 네비게이션: `[ 특별학습 ]` 메뉴 활성화.
  * 하위 탭: `[ 우주탐정단 ]` 탭 구성. 해당 탭 클릭 시 우주탐정단 인트로 화면으로 전환.

### 3. 우주탐정단 인트로 (Intro Screen)
* **목적**: 서비스 진입 및 진단평가 시작 안내.
* **UI 구성**:
  * 현재 작성된 `우주탐정단 타이틀.html` 디자인 적용 (우주 배경, 네온 타이틀).
  * 인트로 영상 플레이어 영역 (시연 시 영상 재생).
  * 화면 하단 중앙 `[ START ]` 버튼.

### 4. 사전 진단평가 팝업 (Diagnostic Evaluation Popup)
* **목적**: 학습자의 현재 수준(AI 개념 파악 등)을 측정.
* **로직**: `[ START ]` 버튼 클릭 시 팝업 오픈.
* **UI 구성**:
  * 제공해주신 `진단 평가 문항 (10문항).md` 기반 10개 문제 순차 제공.
  * 문항 텍스트 + 객관식 선택지 4개.
  * 문항 하단 `[ 다음 문항 ]` 및 진행 상태바 (예: 1/10).

### 5. 진단 평가 결과 대시보드 (Result Dashboard)
* **목적**: 평가 결과 피드백 및 맞춤형 학습 유도.
* **UI 구성**:
  * 환영 메시지: "안녕! 신입 탐정!" (`images` 폴더의 캐릭터 활용하여 캐릭터가 말하는 말풍선 UI).
  * 평가 결과 시각화 (정답 수, 현재 이해도 등).
  * `[ 추천 학습 리스트로 이동 ]` 버튼.

### 6. 추천 학습 (콘텐츠 리스트 화면 / Learning List)
* **목적**: 1~4 파트 및 24차시로 구성된 전체 맵/목록을 보여주고 진입 유도.
* **UI 구성**:
  * 상단: 전체 진행률 및 뱃지 획득 현황.
  * 메인 영역: `차시 제목별.md`에 명시된 4파트 24차시 맵 형태 구성.
  * **인터랙션 포인트**: 샘플 콘텐츠 시연을 위해 **"2파트 사고력 별 > 6차시 — 인공지능의 자신 있는 거짓말"** 카드만 클릭 가능하도록 활성화 처리 (나머지는 비활성/잠금 처리).

### 7. 학습하기 화면 (Learning Detailed Screen)
* **목적**: 6차시에 해당하는 실제 학습 모듈 플레이.
* **UI 구성**:
  * 타이틀: "6차시 — 인공지능의 자신 있는 거짓말"
  * 도입 - 개념 - 영상 - 실습 - 요점 - 마무리 형태의 컨텐츠 영역 설계.
  * 하단 `[ 학습 완료 ]` 버튼.

### 8. 학습 종료 및 복귀 (Back to List)
* **로직**: 7번 학습 화면에서 `[ 학습 완료 ]` 시 결과가 저장되고 6번 '콘텐츠 리스트 화면'으로 복귀.
* **상태 업데이트**: 리스트로 돌아오면 6차시 아이콘이 '완료' 상태로 변경되며 연관된 뱃지 획득 이펙트 표시.

---

> [!TIP]
> 위 흐름대로 화면들을 연결하면, 로그인부터 6차시 학습을 마치고 뱃지를 획득하는 부분까지 하나의 매끄러운 **프로토타입 시연 흐름**이 완성됩니다.
